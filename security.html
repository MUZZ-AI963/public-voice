People’s security pack

If you sound out power, protect the channel. Censorship and control travel through the network and the device. These tools are a reasonable defence so people — and AI assist on the people’s side — can still reach primary sources and put an explain-ask on the desk.

Why this matters now

Authoritarian control does not only silence a letter. It throttles search, blocks mirrors, watches the default browser, and tries to keep machine-speed history away from ordinary people. Tor, a amnesic OS, a no-logs VPN, and a Linux base are how many people keep a lawful public-record path open. Public Voice stays primary-source only; this page is so you can reach those sources and stay anonymous when you choose.

Full package (official links only)

1 · Tor Browser

Routes traffic through volunteer relays so your ISP and the site see less of who you are. Use it when opening Public Voice, Hansard, FOI pages, or mirrors in a hostile network.

Get Tor Browser (torproject.org)

2 · Tails OS

Amnesic Linux you run from USB: leaves little on the laptop’s disk, forces Tor for outbound traffic. For high-risk sound-out sessions when the machine itself may be watched or shared.

Get Tails (tails.net)

3 · Proton VPN

Encrypts the path to the open internet when Tor is blocked or too slow. Prefer the publisher’s own apps and published no-logs posture; verify on their site.

Get Proton VPN (protonvpn.com)

4 · Linux (daily OS)

A free OS you control. Fewer silent vendor locks; easier to keep tools honest. Start with a mainstream desktop (Debian / Ubuntu / Fedora) for every-day work, then add Tor.

Debian download Ubuntu desktop

5 · Kali Linux (security toolkit)

A Linux distro packed for security research and defence testing — for people who need that toolkit. It is not required to use Public Voice. It is not a guide to attack others. Use only on systems you are allowed to test; keep the people’s ledger on primary sources and lawful pathways.

Get Kali (kali.org)

Suggested stack

  1. Everyday: Linux desktop + Tor Browser (+ Proton VPN if the network blocks Tor).
  2. Higher risk: Tails from USB → Tor → Public Voice desk → anonymous seal → copy Send pack yourself.
  3. Toolkit users: Kali only where you already understand defensive/research use — still open Public Voice in Tor when sounding out.
Limits

This page does not teach hacking, evasion of a lawful court order, or access to classified material. It points to public privacy tools so people can stay informed and sound out public records. Not legal advice. Cursor contacts no one. Download only from the official domains above.
